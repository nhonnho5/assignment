# AI log entry

1. File: `docs/ai-log/YYYY-MM-DD-<short-topic>.md` (today's date). Append if it exists.
2. Follow the format of `docs/ai-log/2026-10-13-domain-and-requirements.md`: Tool, Phase, Artefacts produced, then a table `AI proposal | Decision | My rationale`.
3. Fill **AI proposal** and **Decision** (Accepted / Modified / Rejected) from this conversation, factually.
4. Leave **My rationale** as `*(write in your own words)*`. Never write the rationale for the user — it is assessed as their own work.
5. Tell the user which rows need their rationale.
